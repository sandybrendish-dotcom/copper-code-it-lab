## Expansion considerations

The system has limited internal SATA connectivity.

A six-port ASM1166 SATA controller has been considered for future storage expansion.

Any expansion must preserve:

- airflow;
- power supply limits;
- drive cooling;
- recoverability;
- clear documentation.
