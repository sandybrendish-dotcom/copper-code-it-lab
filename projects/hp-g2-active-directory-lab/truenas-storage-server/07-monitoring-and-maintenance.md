# Monitoring and Maintenance

## Routine checks

- Pool health
- Disk SMART information
- Storage capacity
- CPU temperature
- Application status
- Snapshot completion
- Backup completion
- Email alerts
- Network connectivity

## Observed operating behaviour

During initial Immich photo indexing, CPU usage increased significantly and temperatures reached approximately 60°C.

This was monitored while the application processed the library.

## Planned maintenance schedule

### Weekly

- Check alerts
- Check pool health
- Confirm applications are available

### Fortnightly

- Review snapshots
- Review backup results

### Monthly

- Check disk health
- Review capacity growth
- Confirm restore documentation remains current

### Periodically

- Perform a restore test
- Review application updates
- Inspect cooling and dust
- Test UPS behaviour once integrated
