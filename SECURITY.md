# Security Policy

This repository is public and contains sanitised documentation only.

Do not commit:

- passwords or password hints;
- API tokens or authentication keys;
- private certificates;
- customer information;
- device serial numbers;
- public IP addresses;
- complete configuration backups;
- unredacted screenshots;
- private domain or DNS records.

If sensitive information is committed accidentally:

1. remove it from the repository;
2. rotate the exposed credential or key;
3. review the commit history;
4. document the incident privately.
